# Sharing DuoDeck

These are reusable announcement drafts, not a record of a post or marketplace approval. Use a community's own rules and describe the preview limitations. Add a real, privacy-reviewed demo when one is available.

## English draft

DuoDeck is a touch-friendly Omarchy Quattro dock for wide displays and laptop second screens. It brings workspace previews, a local recent-app launcher, sound/brightness/media controls, system metrics and local Markdown memos together. English, Simplified Chinese and Traditional Chinese are supported.

The 0.1.2 preview requires the current Hyprland Lua dispatch API. It keeps notes locally and does not automatically change monitor layouts or key bindings. Hardware feedback and translation contributions are welcome.

Try it: https://github.com/quedulex/duodeck

If it is useful to you, Star the repository to bookmark it; Watch → Custom → Releases follows new previews.
